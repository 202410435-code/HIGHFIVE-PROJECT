# BABSI Baliuag Cebu Lechon — Management System

GitHub Pages-ready version of the existing BABSI management system.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
This repository includes a GitHub Actions workflow in:
`.github/workflows/deploy.yml`

After pushing to the `main` branch:
1. Open **Settings → Pages** in the GitHub repository.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Wait for the workflow under **Actions** to finish.
4. Your site will be available at:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The existing HTML, CSS, JavaScript, images, layout, and functionality were preserved.
